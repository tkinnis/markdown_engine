CommonMark
: A strongly defined, highly compatible specification of Markdown.
: Maintained with an automated test suite of 652 examples.

GFM
: GitHub Flavored Markdown extending CommonMark with tables, task lists, strikethrough, and autolinks.

    Supports multi-paragraph definitions when indented by four spaces.

`MarkdownOptions`
: Immutable configuration object with **presets** for CommonMark, GFM, and extended modes.
